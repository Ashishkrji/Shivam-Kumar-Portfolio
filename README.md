# Shivam Kumar — Personal Portfolio Website

<!-- ![Portfolio Preview](Profile-image.jpeg) -->

A modern, executive single-page portfolio website built for **Shivam Kumar**, an MBA student specializing in **Human Resource Management** and **Business Analytics**. The portfolio showcases professional expertise, academic achievements, core competencies, and personal projects with an immersive, animated user experience.

## ✨ Features

- **Dynamic Scroll Animations**: Powered by Alpine.js Intersect plugin for smooth, delayed entrance animations as elements enter the viewport.
- **Glassmorphic Sticky Navigation**: Responsive navigation bar featuring a translucent blur backdrop, active section tracking, and mobile hamburger menu.
- **Interactive Grid Layouts**: One-row horizontal grids for Education and Work Experience showcasing detailed two-line descriptions and core achievements.
- **Premium Aesthetics**: Ambient background gradients, floating decorative orbs, card tilt/lift hover effects, and customized focus rings.
- **Fully Responsive**: Flawless scaling across mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

- **HTML5**: Semantic and accessible markup.
- **Tailwind CSS (CDN)**: Modern utility-first styling with custom theme extensions, colors (`#0f766e` teal accent), and animations.
- **Alpine.js**: Lightweight reactivity for scroll tracking, active section highlighting, and mobile menu toggling.
- **Alpine Intersect**: Viewport intersection triggers (`x-intersect`).
- **Google Fonts**: Inter font family for sleek executive typography.
- **FontAwesome 6.4.0**: Scalable vector icons.
